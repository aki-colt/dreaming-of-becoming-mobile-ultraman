# 第一卷战场尺度与机战空间

> 按作者要求，重要宇宙战场采用至少百公里级的整体作战空间。以下是供大纲与正文采用的空间基准；保留人物、胜负、既有配机与最终会战资源数量。设施内部战斗仍按真实舱室尺寸写，不把每条走廊放大到百公里。

## 一、各层空间都实际影响战斗

| 层次 | 本卷采用的范围 | 具体功能 |
|---|---|---|
| 第一章联合轮训C区 | 160×120×80公里 | 多条进场路线、纵深航标、侧翼切入、撤离与回收区；四对四是其中的训练科目 |
| 通常宇宙交战整体 | 宽100—300公里、纵深80—200公里、厚度30—100公里 | 前哨、舰艇、转运与撤离节点分布其间，争夺航路而非排成一列对射 |
| 港区外侧整体防御 | 宽100—200公里，向外延伸约100公里 | 舰艇接近、外锚地、工业设施与港口入口联动；内部局部火线另缩放 |
| 最终会战主体空间 | 约800×500×300公里 | 多个方向的舰队、门区、工业目标、补给及撤离节点；关键部署彼此隔几十至数百公里 |
| 战术分区 | 宽约20—80公里 | 小队／中队分工、侦察接力、交叉接敌与火力支援 |
| 分队实际交火 | 约2—15公里，通常在较大分区内移动 | 普通步枪、导弹、动能枪与掩体构成局部胜负 |
| 缠斗与贴身接触 | 约100—800米；真正刀盾接触为数米至数十米 | 短侧闪、快速翻身、压枪、换刀与反向制动 |

宏大来自多个有距离、有航时、有后果的任务同时发生。前沿被击穿会迫使几十公里外的预备队改航，受损补给节点会使更远的分区缺弹；不能只在开头报“八百公里”，之后所有敌我始终围着同一艘船打。

上表是作战包围盒与部署尺度，不规定殖民地工业环或星门本体直径，也不意味着空域被机体均匀填满。四机小队只能控制有限射界和通路，不能单独占满整个160公里空域。

## 二、第一章的160公里演习如何安排

C区采用随训练基地轨道运动的局部参考系，坐标单位公里。空间边界x为−80至+80，y为−60至+60，z为−40至+40。航标、退役船体和障碍集群只占若干小区块，其间保留长距离真空通路；模拟系统重建远端环境与判定，实体训练设施的施工尺寸另定。

| 节点 | 参考位置／关系 | 影响选择的距离 |
|---|---|---|
| 蓝方进入航标 | (−60,0,0) | 与最终突破信标沿主轴约120公里 |
| 外层识别门 | (−20,0,0)附近 | 必须完成身份／态势判读；还剩约80公里纵深 |
| 中段航路门 | (+20,0,0)附近 | 通往最终目标约40公里；可选择高侧或低侧进场 |
| 两侧绕行弧 | 中段y约±20—30、z约±10—20 | 能避开正面火控，增加约20—40公里航程和时间 |
| 货栈-04与最终信标 | (+60,0,0)附近，局部障碍区约8×6×4公里 | 小说开场可直接从距货栈11公里的最后进场写起 |
| 救援、撤离与回收线 | 目标侧后约10—30公里，沿安全方向布置 | 受伤者不能默认原地等母舰下一秒出现 |

完整科目沿主航路约120公里，既有四机蓝方执行编队护航与突破，红方仍为三台游隼家族机与一台护港；不因空域扩大追加数十架实际对抗机。远端舰艇、其他训练分区及中继可作为演习态势／预置环境，不替这八台机体凭空取得击毁数。

蓝方进场段相对航标约0.6—0.8km/s，依靠惯性航行，接近最后交火区前用持续推力降速。整个科目通常约4—6分钟，绕行或救援会挤掉目标时间窗。开篇可以省略前段航行，把航路图、剩余时间、侧翼回报和撤离方向带入当前冲突。

局部护航间隔通常0.6—1.5公里，纵深梯次约1—3公里。阿缪莎利用的四秒盲区，是最后数百米的切角和射界变化，不是从四公里外由静止冲到目标身边。她破坏的首先是互相掩护的射界，随后相对漂移与红方阻拦才将间距扩大到约3—8公里；不能在四秒内无代价拉开十公里。

罗亚回援需要先放弃射位、配准三号机的漂移速度，再接近承力部位。接触或接索前通常把相对速度压到5m/s以内；不能用软索瞬间吃掉几百m/s的速度差。阿缪莎即使转身只需约一秒，也仍要摆脱红方、消掉当前速度分量并追上移动中的友机。人物争执应围绕这些行动的不确定性及任务窗口展开。

三号机仍可以因真实推进故障而面临实体障碍危险，训练失败与人员危险分别判定。最终救援不能让拖带后的两机继续沿用单机3g：两台143—146吨机抱在一起，总质量约289吨；一台指挥型反推约4.15MN，只能贡献约1.46g，且为短脉冲。再加入丹尼尔也须把三机质量、1.2MN索具额定拉力、受损机残余推力一并算入。若要完成较长制动，需更早配速、绕开碰撞路径或利用合格锚点，不能把原单机短脉冲直接持续十几秒。

本轮先确立机设与大纲。现有第一章中“1.68g／2.04g”等无工作点说明的数字应在下一次正文修订时明确为常规高比冲值；快转与急射采用本次新增工作点。正文的推进阀故障、拖带制动、散热声与时间窗需按新设定联动核对，不在本文件假定已经修过正文。

## 三、百公里航时与制动表

以下从相对静止出发，到目标附近重新降至相对静止，以持续1g、前半程加速后半程减速作理想比较。它们不使用4—6g短脉冲冒充持续推力，也未计躲避、损伤与射位准备。

| 两节点距离 | 理想转场时间 | 中点最高相对速度 | 总速度增量消耗 | 叙事含义 |
|---|---|---|---|---|
| 5公里 | 约45秒 | 约0.22km/s | 约0.44km/s | 几公里外也不保证赶上十秒窗口 |
| 20公里 | 约90秒 | 约0.44km/s | 约0.89km/s | 接替一处侧翼需要提前部署 |
| 50公里 | 约143秒 | 约0.70km/s | 约1.40km/s | 临时救火显著消耗整个架次预算 |
| 100公里 | 约202秒 | 约0.99km/s | 约1.98km/s | 横越普通战场是三分钟以上的决策 |
| 200公里 | 约286秒 | 约1.40km/s | 约2.80km/s | 超出标准04默认混合任务约2.48km/s预算，需改任务／补给／降低速度 |

表中后三项也说明：即使时间上能到达，仍可能没有足够工质接战和返航。100公里急赴战后几乎用掉标准04混合预算，不能接着再来一次相同往返。20%工质预留不是默认任意挥霍的额外战斗燃料。

若把转场巡航压到0.5km/s，100公里采取1g加速、惯航、减速，理想约251秒、总Δv约1km/s；约4分11秒，用更多时间保留作战余量。航路折线、避火和舰队位置改变会继续延长。

## 四、怎样看见百公里外并在近处交战

普通猎兵的被动发现约250公里，稳定火控跟踪约35公里，强噪声下预算约7公里；觇星约600／80公里；战略机约1000公里以上发现、130—200公里跟踪。发现一个热源、确认敌我、建立火控解是三件事。己方共享坐标不自动让每把步枪获得舰队级测距精度。

前出侦察、舰艇传感器、通信型机和信标把分区接起来；典型信标清晰链路约30公里，计划上以20—25公里间隔并布置备用路径，不能只拉一条正好顶满距离的线。节点被遮挡或击毁后，远端分区可能继续作战，却暂时失去最新敌我图。

百公里光行时间约0.33毫秒，千公里也约3.3毫秒。紧张的“等不到回答”应来自遮挡、干扰、转发、处理、权限或人没有回答，不能在这个尺度把无线电天然延迟写成数十秒。

普通步枪仍在约2—8公里争夺有效射界，狙击枪有稳定条件可到25—40公里，战略支援炮理想上限约80公里。舰艇和预警节点可以参与更大范围的探测、部署与远程火力，但本轮不为未知舰型擅定一百公里必中的主炮。百公里战场不要求每台M-U隔着百公里开火。

## 五、最终会战的八百公里布局

主体空域约800×500×300公里，按实际门区和工业设施位置裁剪。可划为门区主轴、工业环接近线、上方迂回区、下方补给／撤离区等若干方向；这些是作战分区，不额外命名实体星门或新增一座殖民地。

关键节点通常相隔80—200公里，战术分区相隔20—80公里。前出侦察在主力前方数十公里更新态势，舰艇保障后路，战略机与中型分队围绕有限主目标布置。跨越整片八百公里空域是十几分钟乃至更久的行动，须按速度预算设计惯航段、母舰前移或预先部署；不能把整片空域当作所有人随时能互救的竞技场。

最终会战既有三台镇岳核心配置（通用、拘束、舰队火力）与四只未成熟凯鲁比姆继续保留；四台驭兽中的一台采用R中继配置时仍是四台、八名机组，不把配置另算第五台。缄索的平行试验不直接加入本卷战斗。

怪兽与控制机选择一两处关键方向突破，其他分区仍由舰队、常规M-U、护航与补给体系支撑。断掉控制节点只改变对应怪兽的控制状态，不能把整个八百公里战场一键清空。镇岳原有独立迁跃另受自身专项限制，不给普通M-U普及迁跃，也不替代被封锁的星门航路。

## 六、正文采用尺度的办法

每次从战区切到近景，至少给出一个可追踪的距离与一个任务关系：例如“预备队离中继四十公里，至少两分钟才能接上”，再切到“护航机距友机六百米，盾面遮住它的左侧”。距离一经报出，就随速度、时间和任务变化，不反复凭需要伸缩。

大尺度场面可交替呈现前沿、后方和远端航路的状态：一处的几十秒窗口，会改变另一处分队几分钟后的命运。局部高速翻身和连射仍可以写得很紧；增援来不及、航路被迫绕远、返回工质不足则把百公里尺度落实为人物必须承担的选择。
