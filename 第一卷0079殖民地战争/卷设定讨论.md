# 第一卷《0079殖民地战争》卷设定讨论

本文件记录第一卷所需的战区组织、部队番号、隶属关系与实际运用。与《卷大纲》、总体剧情骨架、《M-U型号设计》和《M-U装备武器设计》配套使用。

本轮补充为军队番号与编制设计，供正文后续统一采用。保留已出现的巴纳德第三基地、第一批中央维和特遣队、罗斯154地方守备旅第三大队等称呼，补足它们的正式名称和组织关系。新增番号不表示现有章节已经完成校准；文末列出需要处理的称呼冲突。

## 一 战争中的EUC武装体系

UC0079殖民地战争发生在EUC内部。中央派、地方自治派与倒戈驻军之间不仅共享训练、装备和接口标准，也曾共享军籍、补给与指挥制度。番号可以表现这种共同来源：凯伊的部队在兵变以前就是EUC正规驻军，中央军认识他们的旧识别码，双方维修人员也能读懂同一种枪械的标签。

政治立场与军种、出生地不直接对应。殖民地出身者可以效忠中央，驻扎地方多年的军官也可能拒绝地方总督的请求。同一旅可能分裂，同一舰队的舰艇可能收到不同任务，不能用“地方军”一词概括全部反中央力量。

| 系统 | 法定归属与任务 | 第一卷中的内部差异 |
|---|---|---|
| 中央直属与跨星区增援 | EUC武装部；中央战略预备、远程投送、战略M-U | 强调统一指挥，但不同参谋、部队和保障机构对风险有不同判断 |
| 巴纳德星区常驻军 | 武装部所属两大军种，经星区联合司令部协调 | 总体保留中央军籍；有人主张强硬处置，有人要求地方调停，有人倒戈 |
| 罗斯154与卡斯特正规守备部队 | 地面军或空天军的地方常驻编制 | 长期承担本地防务，对居民与工厂有实际依赖；兵变以部分单位为起点 |
| 地方公共安全与设施治安 | 公共安全部及殖民地政府的法定治安体系 | 有的协助中央，有的保卫社区，有的被工会吸收；不自动列入正规军序列 |
| 企业警备与承包保障 | 持牌企业，受当地政府及相关中央机构监管 | 保卫工厂、船坞和货物；可能分裂或支持一方，不能直接获得军方指挥权 |
| MCD调查与怪兽应对人员 | 独立调查系统 | 向战区提供巨大生命体研判，拥有任务上的独立性，不指挥整个空天军 |

“EUC各方势力”在这里首先落实为不同指挥、供给与职责关系。正文通过谁能调船、谁能批准开火、谁掌握居民名单、谁要承担停产后果表现其差异，不给每支部队贴一个永久不变的善恶标签。

## 二 指挥层级与权限

### 战前与战时

**战前：** 武装部制定战略与任免高级军官；巴纳德星区联合司令部协调本星区空天军、地面军和军事保障。巴纳德总督可提出救援、防卫与治安协助请求，但不能自行命令中央战略机群，也不能撤换星门控制系统的中央授权人员。

**冲突升级后：** 武装部在既有联合司令部基础上启用“巴纳德—罗斯联合战区司令部”，下辖空天作战、设施作战、联合保障等任务指挥机构。它是针对本次战争的指挥机构，并非EUC全境进入总动员。跨星区增援在划定任务中受战区作战指挥，军籍、工资、装备档案和长期维修仍由原单位负责。

**怪兽投入后：** 战区成立反怪兽联合指挥席，协调战略M-U、舰队、工程与撤离任务。反怪兽指挥席接管相关作战扇区，不把所有医院、地面警戒和敌后侦察都变成战略机群的直属单位。

### 作战指挥与行政隶属

| 关系 | 含义 | 例子 |
|---|---|---|
| 归建 | 回到原编制单位 | 完成白线任务的小队回第214大队登记、补给和补充人员 |
| 配属 | 限定任务或时段内接受另一指挥部的作战指挥 | 第214大队一个中队配属第一维和特遣队 |
| 协同 | 约定目标、射界、时段和识别程序，不改变隶属 | 空天军机群掩护地面军清理舱门 |
| 支援 | 提供火力、运输、工程或情报，不必交出全部指挥权 | 工程营协助公共安全部门封堵失压舱 |
| 接管 | 根据具体命令接手某项任务、设施或管制权 | 战区接管军用船坞防卫，不等于接管所有民用厂房 |

公共安全部特派文官可以根据授权要求拘捕、确认治安目标及提出行动优先级，不能绕过指挥程序直接操纵所有机组。军事指挥员可以暂停不具备安全条件的动作，并负有说明与上报责任。冲突来自授权解释、风险取舍和问责压力，命令必须有可识别的来源。

## 三 正式番号、编组代号与通信称呼

### 番号规则

1. **空天军舰队采用全军独立序列。** 第六舰队是第六个正式舰队番号，不表示只能驻第六行政星区。所属巡防支队、机动大队与舰艇各有编号。
2. **地面军旅采用全军旅级番号。** 正式写法如“地面军第417设施守备旅”；营、大队和连的数字在旅内编号，单独写“第三大队”容易混淆。
3. **中型M-U单位以大队—中队—小队为主。** 大队通常有全军独立番号，中队与小队在上级内部编号。
4. **战略M-U有独立的军团—群—分队序列。** “军团”在此为辖多个战略群及保障单位的组织层级，不等于数百台机体同时抵达一个战场。
5. **临时编组采用战区＋任务序列。** 正式文书写“巴罗斯第一维和特遣队”；公报和人物对话可简称“第一特遣队”。后文的中央增援不会因此改名为“第二舰队”。
6. **地方治安与企业单位必须带来源。** “卡斯特工业环警备总队第三大队”与“第417守备旅第三大队”不是同一单位。

番号不编码所有政治与地理信息，也不以编号大小表示战力。部队换防、倒戈、减员和重建后，其番号与实际实力可能差别很大。

### 文书与频道示例

| 场合 | 建议写法 |
|---|---|
| 首次交代人物所属 | 空天军第六舰队第214机动M-U大队第一中队第一小队 |
| 同一任务中的日常叙述 | 214大队、第一中队、罗亚的小队 |
| 跨单位命令 | 第214大队第一中队配属巴罗斯第一维和特遣队，原隶属与保障关系保留 |
| 无线电呼号 | “远望先遣，蓝一请求撤回。”任务呼号不替代档案番号 |
| 部队机号 | 零号机、二号机；随编队分配，不是机体型号，也不保证跨任务唯一 |
| 政治宣传 | 中央维和部队、罗斯地方防卫军；这是政治称呼，应能追溯正式单位 |

“白线”“通道”“断脉”分别是任务或行动称呼，不能因换任务就让驾驶员在档案里自动转入新军种。频道同名可以存在，但叙述必须让读者知道正在说谁。

## 四 M-U编制规模基准

以下为第一卷写作基准，不是全EUC所有部队绝对相同的编制。表中台数指主要任务机，训练、维修、补充和备用机另列；实际出动数量必须扣除故障、战损、留守与已分配任务。

| 类别与层级 | 常见编制 | 指挥与组织意义 |
|---|---|---|
| 轻型设施小队 | 4—6台5米级 | 一个通道、警戒点或抢修作业面；军士或基层军官指挥 |
| 轻型设施连 | 18—24台，分为若干小队 | 配有工具、运输、无人系统和维修人员；并非只有驾驶员 |
| 轻型设施营／守备大队 | 通常3个任务连，加指挥保障 | 负责一组重要设施，人数远多于M-U数量 |
| 中型宇宙小队 | 通常4台15米级 | 上尉或有经验的中尉任队长；可按任务拆成两机组 |
| 中型宇宙中队 | 通常3个小队，12台任务机 | 少校或资深上尉指挥；负责轮换、扇区与跨小队协调 |
| 中型机动大队 | 通常3个中队，36台任务机，另有保障与备用 | 中校或资深少校指挥；并非36台随时全部可用 |
| 战略M-U分队 | 常见3台50米级任务机 | 三台已需大型工程、运输与保障资源；分队长不等于军团长 |
| 战略M-U群 | 常见3个任务分队，共9台，另有补充与保障 | 群级司令部负责轮换、母舰协同和大型维修 |
| 战略M-U军团 | 多个战略群与独立保障单位 | 中央战略组织；本卷只抽调其中少数分队 |

旅是混合组织，可以有轻型设施营、中型重力作战单位、无人火力、工程与运输。地面军第417旅保留“第三大队”这一地方沿用称呼，作为旅内混合机动守备单位；不因为叫大队就必须与空天军36台宇宙机大队同编制。

大型舰艇是否携带M-U，取决于机库和保障能力。巡逻舰、护卫舰名称不自动对应固定载机数量，轻型设施机可以由普通运输船运送，中型宇宙机则需要对应出动与回收条件。

全EUC约1000台50米级M-U分布在多个任务与维修序列。此数字不能按一个军团、一个战区或一次会战照搬。

第31群的调动与公开信息不必同步。卡斯特四日冲突中已经出现外围战略机，不应在最终会战再说“战区此前从未部署五十米级”。第72章可以表现战略机从外围待命转入反怪兽交战，以及专门指挥程序启动。

## 六 主角、埃德加与训练基地的归属

### 战前

**巴纳德第三轨道联合战术训练基地**是基地名称，简称第三基地。它提供联合轮训、机库、试验场地和保障，不等于第三舰队或第三M-U大队。受训人员可以来自不同常备单位。

| 人物／单位 | 正式关系 | 正文运用 |
|---|---|---|
| 罗亚·卡斯维尔，上尉 | 第214大队第一中队第一小队队长 | 常规4台任务机；丹尼尔属于此小队，“二号机”是当前编队机号 |
| 阿缪莎·雷恩，中尉 | 从军械试验评估岗位调入第214大队第一中队；初期在第一小队完成联合轮训与适应 | 罗亚有训练与任务上的指挥关系；“零号机”可作为她在试验转入阶段沿用的呼号，须在当次编队登记 |

### 初期分队与后续调动

初期维和将第一中队拆成前出、留守和轮换三个4机小队。罗亚率第一小队前出；阿缪莎从联合轮训小队临时调入留守小队，保留军籍，第一小队的空缺由完成训练的轮换机组补齐，总编制仍为12台。她后续承担护航负责人，可以指挥一个4机分队及任务配属的运输、救援联络人员；中尉的职位与资历足以解释这一职责，不让她突然指挥整支舰队。

罗亚回归后先回第一中队登记、审查和补装，远望门行动后再调至第62特种侦察大队。埃德加通过任务报告与人员推荐推动调动，最终批准来自战区和相关单位，避免由一个支队长随意改变所有军籍。

| 后期单位 | 所属与任务 | 人物关系 |
|---|---|---|
| **第62特种侦察M-U大队** | 战区敌后作战处的执行单位；军籍属于空天军任务序列 | 被动侦察、导航与补给节点行动，不是拥有独立战争权限的秘密军团 |
| 第62大队第二中队第一小队 | 罗亚调入后的4机小队 | 罗亚继续以上尉任小队长；伊万等队员按正文名册登记，不预设全部来自原队 |
| 战区敌后作战处第二行动科 | 任务制定、资料审核与报告汇总 | 正文中罗亚接触的“第二处”统一为其旧称或口语简称；首次出现需说明正式名称 |
| 战区航道封锁协调组 | 战区空天作战体系的临时参谋组织 | 埃德加在初战后担任组长，兼敌后任务协调职务；中校负责一个工作组，向战区更高指挥员报告 |
| 白线临时护航编队 | 以214、219大队抽调机组为主，战区授予限定护航任务 | 阿缪莎负责一侧的现场护航；任务结束或扩大撤离后更换配属，不更换原单位番号 |

埃德加不在本卷未经交代晋升为战区司令。他能影响目标清单、封锁优先级和罗亚的任务，来自具体参谋授权及与上级的关系。战区对战略机群和大规模舰队动作的最终决定仍由更高层承担。

## 八 倒戈驻军与联军的旧番号

### 第417守备旅的分裂

正式全称：**EUC地面军第417设施守备旅，罗斯154驻防**。它有本地招募人员，也有中央轮换军官；主要职责是居住设施、采掘节点与军用仓库的安全。

- **旅部与中央联络单位：** 兵变后部分人员被扣留，部分撤向中央控制的哨站。旅部无法再向全旅有效下令，但档案上的番号不会当天消失。
- **第一设施营：** 分裂，一部分继续接受中央命令，一部分保护居民区并拒绝参与进攻。局部中立不等于已经加入联军。
- **第二设施营：** 以矿区和物资仓库警戒为主，倒戈与观望交错；兵力与任务不能整齐按营一分为二。
- **第三机动守备大队：** 首个公开抗命的核心单位，拥有卫士、少量驻防猎兵以及运输与拖带力量。凯伊属于其中的宇宙机动中队。

正式关系为“第417旅第三机动守备大队第二中队，凯伊所率第一小队”。凯伊以中尉指挥4机小队，依靠本地经验与军中信任成为前线代表。他可以带领临时合编组，不因公开抗命便直接成为全旅旅长。

该旅少量M03-D采用跨军种配发和训练，在设施外侧执行巡检、港区护航；主力保障依靠本地船坞。拥有这些机体不使整个地面守备旅变成空天舰队。

### 远望门守备力量

**远望门联合守备司令部**协调两端守备，但两端各有现场指挥、人员与认证链。

| 单位 | 战前任务 | 兵变与战争中的位置 |
|---|---|---|
| 空天军第6星门警戒支队 | 航道外侧识别、导航外围与船只警戒 | 巴纳德侧主力保留中央指挥；罗斯侧分遣队内部出现倒戈与被隔离人员 |
| 地面军第118星门设施守备营 | 气闸、调度中心、控制室与生命维持防卫 | 罗斯侧部分连队响应417第三大队，中央派军官被扣留；仍有小股忠诚残部 |
| 星门工程值班组 | 星门及交通部门的技术值勤人员 | 有操作权限但没有舰队指挥权；被迫中断认证、保护设备或协助有限恢复 |

兵变需要现场控制、人员扣押和认证链被破坏，不是一个中尉通过无线电命令就能关闭两端全部星门。巴纳德侧保留中央控制，也不能绕过罗斯侧缺失的安全条件强行运行。

### 联军中的沿用与改称

| 战前来源 | 联军时期称呼 | 实际组织与写作边界 |
|---|---|---|
| 第417旅第三机动守备大队倒戈部分 | 罗斯地方防卫军第三机动大队，仍常被称“守备旅三大队” | 旧档案、军衔与地方委任并存；不把剩余全旅算成同一支忠诚部队 |
| 凯伊所属小队与补充人员 | 罗斯防卫军第一机动中队，前身来自旧第三大队第二中队 | 战时才逐步扩为中队；凯伊保留旧军衔，地方指挥职务不自动获EUC承认 |
| 丹尼尔选择留下后加入的机组 | 罗斯防卫军第一机动中队任务小队 | 通过临时委任与地方档案登记，使用M03-D；不是原中央小队整体倒戈 |

| 倒戈基层治安单位与居民自卫组 | 居住区联合警备队，按区段标识 | 多支独立组织，不设统一的全域军籍；仅参加约定的防卫任务 |

“殖民地联军”是政治与联合行动称呼。联合协调会可以分配航路和共同目标，各组成单位仍掌握自身人员、弹药与撤退决定。星联的驭兽机组作为秘密援助作战组加入，不能伪装成第417旅本来就有的制式怪兽连。

战后中央文件以旧军籍与新组织双重登记，例如“原第417旅第三大队第二中队人员，现罗斯防卫军第一机动中队”。这能解释受降与审查中的争执，而不是让所有人自动成为无身份的非法人员。

企业警备队可以与中央军协同，也可能保护中立厂区或向工团移交设备。此时应交代合同、许可、设施控制或人员选择，不能用一个“企业私军”笼统解释它拥有战略舰艇和50米级制式M-U。

MCD研判可以影响军方目标选择，不能仅凭调查组意见停止所有炮击。最终会战中，MCD、战略机群、公共安全和地方能源机构分别知道不同信息，联合指挥席负责把信息变成行动。

## 十一 正文统一清单

1. **第一特遣舰队与第一舰队：** 统一对应巴罗斯第一维和特遣队及其舰艇部分，不误写成整个空天军第一舰队。
2. **舰艇种类：** 第九章的两巡逻舰、四护卫舰作为初期战斗舰基准。后文若有“巡洋舰沉没”，需改回具体损失舰种，或另行交代其来自其他单位，不能凭空加入初期6舰清单。
3. **埃德加职务：** 保留中校军衔，落实36支队长、初期特遣队指挥官和后期封锁协调岗位；战区级决策应说明授权或上级来源。
4. **凯伊职位：** 初期为417旅第三大队第二中队的小队指挥官，战时才获得临时中队指挥职务。不能初期以中尉指挥完整守备旅。
5. **“第七机动队”等简称：** 现有章节中同名单位被写成五米级侦察队、五十米级部队及“第四方”单位，无法作为一个完整番号沿用。后续需按具体场景分别归入308旅任务队、31群战略分队或联军临时队；第一次出现给出来源，不用一个设定强行抹平冲突。
6. **小队大小与机体大小：** 小队是组织层级，不是5米级的同义词。轻、中、战略机都可组成不同规模的小队或分队；传感器不会因对方更大而自动把它过滤掉。
7. **护航与撤离编组：** “通道”“通道二”保留为任务代号；平民转移办公室提出路线、名单和优先需求，军方派出编队协同，不直接变成军事编队的行政上级。
8. **敌后第二处：** 统一对应敌后作战处第二行动科；任务制定部门与第62执行大队分开。其他“第三处”等名称如需保留，应另行说明功能，不自动与中队序列混用。
9. **最终三台战略机：** 归第31群第一任务分队，三台是核心任务兵力，不代表战区全部战略存量。外围部署到直接参战的阶段差异要一致。
10. **联军中队数量：** 后文出现一个中队带四十余台机时，需区分正规中队、临时撤离集合体及拖带的其他机体；统一名册不能把全体运输对象算作同一战斗中队。
11. **两大军种名称：** 正式名称统一为空天军、地面军；“宇宙军”仅作为有说明的旧称或口语，不能另生出第三个军种。
12. **连续性记录：** 按阶段登记机组的军籍单位、当前配属、任务呼号、可出动数量与装备来源；变动由损伤、命令、补充和人员选择造成。

本轮设定只建立组织基准，后续统一正文时按这份清单处理。番号在正文中首次出现需说清隶属，此后优先使用短称；不要在每场交火前重复完整序列。

## 十二、高机动、连射与百公里级战场

本轮新增[战场尺度与机战空间](战场尺度与机战空间.md)：第一章160×120×80公里，通常宇宙战场宽100—300公里，最终会战主体约800×500×300公里。其间分队交战约2—15公里、缠斗约100—800米，贴身接触仍是数米至数十米。节点相隔几十公里须按分钟转场，不能因为能快速转身就忽略航时。

机设增加[高流量近战推进与快速姿态](../M-U机设/00-高速机动与格斗.md)，标准猎兵-04前／侧／反4／2.5／3g，A型6／4／4.5g，都是短脉冲；常规高比冲工作点保留。原步枪增加储能急射，另补六种[专用连射军械](../M-U机设/00-连射武器与射击节奏.md)，不自动改变既有配机与配装。

最终会战三台镇岳核心配置、四只凯鲁比姆及驭兽中继配置的计数口径保留；大空间通过多方向部署、前出侦察、补给与撤离链体现，不靠重复计算战略机或怪兽扩充战力。
